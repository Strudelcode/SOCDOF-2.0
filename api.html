Local REST API · v2.0.2

Lesen, ohne Schreibzugriff.

Der optionale Kestrel-Server bindet ausschließlich an localhost und stellt aktuelle SQLite-Daten als JSON bereit. Es gibt keine POST-, PUT- oder DELETE-Routen.

Base URL: http://localhost:5050
GET
/api/status

Gibt App-Name, Version, Serverstatus, Read-only-Flag und Basis-URL zurück.

GET
/api/products

Gibt die aktuelle Produktliste mit ID, SKU, Name, Preis, Bestand und Einheit zurück.

GET
/api/sales

Gibt die Verkaufsübersicht mit Auftragsnummer, Datum, Partner und Gesamtsumme zurück.

Die API ist standardmäßig aktiviert und kann über AppConfig.LocalApiEnabled deaktiviert werden. Der Dienst bleibt lokal und read-only.

Windows packaging: Der offizielle Download ist ausschließlich `SOCDOF_setup.exe`. GitHub Actions erzeugt das Paket aus dem self-contained Build, prüft die Installer-Datei und verwendet die passende Release-Dokumentation automatisch.
