## v1.6.0 - 2026-08-25

### Changes

- Added an optional local ASP.NET Core Kestrel server controlled by `AppConfig.LocalApiEnabled` and enabled by default.
- Bound the server to `http://localhost:5050` so the API is available only to local applications.
- Added read-only JSON endpoints: `GET /api/status`, `GET /api/products`, and `GET /api/sales`.
- Added product responses containing SKU, name, price, current stock, and unit.
- Added sales responses containing order number, date, partner, and total amount.
- Added clean HTTP 500 problem responses and server-side error logging without returning exception details.
- Added WPF startup and shutdown integration with resource disposal and graceful server stop handling.
- Synchronized application and project version metadata to `v1.6.0`.

## v1.0.0 - 2026-08-25
