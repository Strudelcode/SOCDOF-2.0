## v1.0.0 - 2026-08-25

### Changes

- Created the initial native WPF application targeting .NET 8 for an offline-first Windows desktop experience.
- Added centralized application identity through `AppConfig.AppName` and `AppConfig.Version`.
- Added operating-system-resolved application storage under `%APPDATA%\\SOCDOF\\` and `%APPDATA%\\SOCDOF\\backups\\`.
- Added `AppDbContext` using Entity Framework Core with the SQLite provider.
- Added database initialization and explicit `PRAGMA journal_mode=WAL;` activation with result verification.
- Added `BackupService` for a startup SQLite backup named `SOCDOF_backup_YYYYMMDD_HHMMSS.db`.
- Added retention cleanup that keeps only the ten newest backup files.
- Added failure logging and incomplete-backup cleanup without deleting the source database.
- Started the application with an empty data state; no mock or placeholder records were inserted.
